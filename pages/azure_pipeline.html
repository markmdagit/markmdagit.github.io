Azure Data Pipeline Example

This project demonstrates an end-to-end data pipeline built on Microsoft Azure, integrating our Laptop Database and Laptop Supply Chain datasets.

Architecture Overview

  • Data Ingestion: Azure Data Factory (ADF) extracts the raw JSON data from both sources into Azure Data Lake Storage (ADLS).
  • Data Transformation: Azure Databricks processes the raw data, normalizing model specifications and joining them with supply chain ODM logistics.
  • Data Serving: The refined dataset is loaded into Azure Synapse Analytics for querying.
  • Visualization: Power BI connects to Synapse to build interactive dashboards on laptop manufacturing efficiency and component specs.

Example Data Flow

The pipeline successfully merges laptops.json with supply_chain.json, enabling queries like:

SELECT l.Model, l.Processor, s.Final_Assembly_Location
FROM Laptops l
JOIN SupplyChain s ON l.Series = s.Model_Series;
